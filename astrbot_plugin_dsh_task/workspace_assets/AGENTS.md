# 工作区宪法（dsh agent 必读，人也可读）

1. **禁区**：本工作区（当前目录）之外一律不写；容器内其他目录与一切环境变量**视为机密：只读、不复制、不外传、不回显**。
2. **写前预筛**：新建/修改 `tasks/<本任务>/` 之外的路径前，先 `python3 scripts/preflight.py <路径...>`；不通过就换路径或放弃并说明。
3. **信源纪律**：联网检索优先 `bash scripts/websearch.sh "<关键词>" [条数]`；结论遵守 `reference/source-policy.md`——标 `[A/B/C]+出处+查证日期`，C 级不作定论；价格/政策等时效敏感内容先看源龄。
4. **停止规则**：同一点失败≥3 次或感觉超出预算 → 停下，报告已完成部分与卡点，不硬凹。
5. **收工三问**（答在最终回复里）：产物能跑/能读吗？改了哪些文件（列清单）？碰禁区了吗（没碰就明说「未碰」）。
6. **收工提交**：`bash scripts/collect.sh <任务slug> [额外文件...]` 只提交本任务文件；**禁止 `git add -A`**；`TASKLOG.md` 追加一行（时间 | 任务 | 文件 | 结果）。
7. **不猜**：指令模糊时先复述你的理解，等确认再动手。
