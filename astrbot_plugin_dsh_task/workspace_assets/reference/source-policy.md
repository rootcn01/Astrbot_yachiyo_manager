# 信源政策（联网任务默认生效）

## 分级
- **A**：一手/官方——政府站点、官网、官方文档、API 文档、论文、统计公报
- **B**：主流媒体、知名技术文档站
- **C**：UGC、SEO 聚合站、匿名博客、营销号

## 三条铁律
1. 关键结论必须标 `[A/B/C] + 出处 + 查证日期`；**C 级不作定论**，须 A 级交叉后才可上报。
2. **时效敏感内容**（价格/促销/政策/版本号）先看源龄：价格类 ~2 周、政策类按发布周期；过期源降级或弃用，并明示「以 X 日期源为准」。
3. **一手优先**：平台政策/价格/规格走官方页或 API 直扒，不信搜索聚合与二手转述。

## 产出前 15 秒预筛
深读前先看元数据：标题像钩子、无日期、无名气的源，先筛掉再决定要不要深读。
